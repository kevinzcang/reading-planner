Can't open from Downloads

This app needs to be hosted on a website to work — browsers block Firebase and external scripts when opening HTML files directly from your computer.

How to use it

Option 1 (easiest): Visit the live site at your GitHub Pages URL
Option 2: Upload this file to GitHub Pages as index.html
Option 3 (local dev): Run npx serve . in the same folder

The downloaded file is not broken -- it just needs a web server.
